Comparative Analysis: Vision Transformers vs ResNet34

An experimental investigation of model performance under different configurations: Baseline ViT, Augmented ViT, and ResNet34 with Data Augmentation. This infographic presents training curves, validation accuracy, confusion matrix insights, and classification reports.

Experiment 1: Baseline ViT

  • Architecture: Vision Transformer
  • Data Augmentation: None
  • Training Epochs: 2
  • Final Accuracy: 91.40%

ViT converges rapidly without augmentation, showing strong baseline performance.

Experiment 2: Augmented ViT

  • Architecture: Vision Transformer
  • Data Augmentation: Applied
  • Training Epochs: 2
  • Final Accuracy: 20.87%

Data augmentation severely hinders ViT convergence in short training cycles.

Experiment 3: ResNet34 + Augmentation

  • Architecture: ResNet34 (CNN)
  • Data Augmentation: Applied
  • Training Epochs: 10
  • Final Accuracy: 91.19%

ResNet34 benefits from data augmentation, achieving stable convergence.

Figure 1: Baseline ViT Training Loss

Baseline ViT (without data augmentation) shows rapid loss reduction from 0.7244 to 0.3200 over 2 epochs, indicating easy convergence in absence of augmentation.

Figure 2: Augmented ViT Training Loss

Augmented ViT shows minimal loss reduction (3.0296 → 3.0070), indicating failure to converge. Data augmentation appears incompatible with ViT in short training cycles.

Figure 3: Augmented ViT Validation Accuracy

Augmented ViT achieves only 20.87% validation accuracy at epoch 2, confirming the negative impact of data augmentation on ViT performance.

Figure 4: ResNet34 + Augmentation Training Loss

ResNet34 shows smooth, consistent loss reduction from 1.7908 to 0.4423 over 10 epochs, demonstrating stable training with data augmentation.

Figure 5: ResNet34 + Augmentation Validation Accuracy

ResNet34 achieves 91.19% validation accuracy at epoch 10, indicating strong performance when combined with data augmentation strategies.

Figure 6: Confusion Matrix Key Insights

Analysis of ResNet34 confusion matrix reveals:

  • Strong performance on majority classes: Diatoms, Fragments
  • Confusion in minority classes: Small-sample classes exhibit misclassification
  • Class imbalance effects: Bright diagonal but scattered off-diagonal points
  • Recommendation: Address class imbalance via weighting or oversampling

Figure 7: ResNet34 Classification Report (Selected Classes)

Class Precision Recall F1-Score Support

ResNet34 shows strong performance on majority classes but struggles with minority classes (e.g., Eucyrtidium_spp, Lithocampe_platycephala), highlighting class imbalance issues. Macro average F1-score (0.6320) is significantly lower than weighted average (0.9154).

Key Findings & Conclusions

ViT-Augmentation Incompatibility

Data augmentation severely impedes Vision Transformer convergence in short training cycles, resulting in near-static loss (3.03→3.01) and poor accuracy (20.87%).

CNN Benefits from Augmentation

ResNet34 demonstrates stable training with data augmentation, achieving smooth loss reduction and final accuracy comparable to Baseline ViT (91.19%).

Class Imbalance Effects

Confusion matrix and classification report reveal significant performance disparities between majority and minority classes, highlighting class imbalance challenges.

Architectural Recommendations

For Vision Transformers, either avoid augmentation or extend training cycles. For imbalanced datasets, implement class weighting or oversampling strategies.
