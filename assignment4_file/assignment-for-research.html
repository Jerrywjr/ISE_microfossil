Research Assignment: Microfossil Classification

Reproducing Baseline Experiments and Proposing Novel Approaches

Due: 5 December 2025 Group Size: 2-3 Students Format: Research Paper (8-12 pages)

Assignment Overview

This assignment challenges you to reproduce the experiments from the paper "Classifying microfossil radiolarians on fractal pre-trained vision transformers" and then propose and implement improvements that could potentially outperform the state-of-the-art results presented in the paper.

Baseline Paper: Mimura, K., Itaki, T., Kataoka, H., & Miyakawa, A. (2025). Classifying microfossil radiolarians on fractal pre-trained vision transformers. Scientific Reports, 15, 7189.

The assignment is divided into two main parts:

  1. Part 1: Reproduce the paper's experiments and validate the reported results
  2. Part 2: Propose and implement novel approaches to advance beyond the current SOTA

Part 1: Reproducing Baseline Experiments

Dataset Acquisition and Preparation

  • Download the SO32 dataset (available as supplementary material in the paper)
  • Recreate the data splits as described in the paper (85% training, 15% testing)
  • Implement class balancing by limiting classes with >1000 images to 1000 training samples
  • Preprocess images to 224×224 pixels while maintaining aspect ratio

Model Implementation

  • Implement the ViT-base architecture (86.6M parameters)
  • Integrate pre-trained weights from:
    • ImageNet-21k (real images)
    • ExFractal-21k (mathematical fractals)
    • RCDB-21k (radial contours)
  • Code available at: GitHub Repository

Experimental Protocol

  • Run 5 iterations with different random seeds for each pre-training condition
  • Train for 40 epochs using SGD with momentum (0.95) and learning rate 0.001
  • Use weighted cross-entropy loss to handle class imbalance
  • Implement class-averaged accuracy as the primary metric
  • Record confusion matrices for the best-performing model

Expected Results to Reproduce

  • CNN baseline: ~78.2% accuracy
  • ViT + ImageNet: ~85.6% accuracy
  • ViT + ExFractal: ~85.3% accuracy
  • ViT + RCDB: ~86.3% accuracy (best)
  • Standard deviations: 0.008-0.015 across iterations
